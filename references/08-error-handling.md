# WSTG-ERRH — Testing for Error Handling

| ID | Title | What it verifies |
|---|---|---|
| WSTG-ERRH-01 | Testing For Improper Error Handling | Error responses don't leak stack traces, internal paths, query fragments, or framework/version details |
| WSTG-ERRH-02 | Testing for Stack Traces | Debug/stack-trace output is fully disabled in the production configuration |
